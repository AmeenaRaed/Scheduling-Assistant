# Scheduling-Assistant

## Chosen project
Intelligent Scheduling Assistant 

## Objective 
- Develop a scheduling system that automatically assigns tasks or classes to available time 
slots based on constraints. 

## Background 
Constraint Satisfaction Problems (CSPs) involve assigning values to variables under given restrictions — common in timetabling and planning. 

## Detailed Tasks 
1. Define variables (e.g., courses or tasks) and domains (available times). 
2. Define constraints, e.g.: 
o "No two courses at the same time" 
o "Instructor A not available on Monday" 
3. Implement a backtracking search algorithm to find a valid assignment. 
4. Display the generated schedule neatly. 

## Expected Output 
Example: 
Course A → Monday 10:00 
Course B → Tuesday 12:00 
No conflicts detected. 
Tools: Python 
Deliverables: Code, example run, explanation of constraints.
